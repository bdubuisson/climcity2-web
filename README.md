# ClimCity2 — version web

Prototype jouable dans le navigateur (ordinateur ou iPad) : **https://bdubuisson.github.io/climcity2-web/**

Jeu de gestion d'une ville en crise climatique et sociale (pollutions, chômage, logement, circulation…) : on construit,
on fait voter des lois et on suit leurs effets sur les indicateurs, à la manière de *ClimCity* (Cap Sciences).

- Version prototype, **sans son** : les musiques et sons du ClimCity original appartiennent à Cap Sciences et ne sont
  pas distribués ici.
- Graphismes générés pour ce projet ; police *Gochi Hand* (SIL Open Font License).
- Construit avec Unity (WebGL). Le code source est dans un dépôt privé.
